# Third-Party Assets And Artifact Boundary

This repository contains original experiment infrastructure and compact
research records. Curated benchmark prompts, model traces, manual-audit
verdicts, and compact runtime receipts are included where needed to reproduce
reported analyses. The repository does not redistribute Qwen model weights,
NuminaMath datasets, generated checkpoints, private operational transcripts,
or uncurated generations.

Users must obtain model weights and datasets from their original providers and
comply with the corresponding licenses and terms. In particular, consult the
current terms for Qwen, veRL, vLLM, EvalScope, NuminaMath, MATH-500, GSM8K,
OlympiadBench, AMC, HumanEval+, MBPP, LiveCodeBench, GPQA, MMLU-Pro, C-Eval,
IFEval, and MGSM before downloading or redistributing any associated assets.

Dated experiment records may contain historical machine paths, run IDs, and
hardware topology descriptions. These are provenance, not current deployment
defaults. Active scripts should derive the repository root or accept an
explicit environment override.
