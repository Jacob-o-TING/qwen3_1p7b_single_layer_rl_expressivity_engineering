# Publication Snapshot

## Provenance

This standalone repository was derived from the `qwen3_1p7b_single_layer_rl`
subtree at monorepo commit:

```text
c464e3a2ef5892c9bf33e9eb06a2f7f6d958e8f5
```

The source subtree was clean at copy time. The original working directory was
treated as immutable while this publication fork was prepared.

## Included

- source code and tests;
- experiment and runtime configurations;
- reproducibility and deployment scripts;
- dated plans and execution records;
- compact metrics, manifests, and publication figures.
- tracked manual-audit inputs, model traces, verdicts, and review queues under
  `audit_inputs/`;
- tracked compact runtime receipts under `runs/runtime_smokes/`.

## Deliberately excluded

- ignored or untracked run outputs, logs, checkpoints, deployment exports, and
  generated caches;
- training datasets and model weights;
- private chat backups and local operational archives;
- credentials, personal machine paths, and ephemeral SSH endpoints.

The exclusions reduce privacy, licensing, and accidental-secret risk while
retaining the bounded evidence required to inspect published measurements.
Dated records may refer to additional omitted artifacts by hash or historical
remote path. Such references are provenance only and do not imply that the
artifact is bundled.

## Editorial normalization

Human-readable material uses neutral scientific prose. Scientific claims,
measurements, negative results, run IDs, and known protocol limitations were
retained.
